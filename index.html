Install

Get KOTOBA in a minute

KOTOBA is downloaded directly from GitHub as an APK file.

Download the APK

Tap Download for Android on your phone. Your browser may ask you to confirm the download.

Open the file

Open KOTOBA.apk from your notifications or the Downloads folder.

Allow the install

If asked, allow your browser or file manager to install unknown apps. You only need to do this once.

Start learning

Tap Install, open KOTOBA, pick your daily goal and begin with あ.

Requires Android 8.0 (Oreo) or newer. To update, download the new version and install it over the old one; your progress is kept.

FAQ

Questions

Is KOTOBA free?

Yes. Completely free, with no ads, no in-app purchases and no account.

Does it work without internet?

Yes, entirely. All lessons are inside the app and your progress is saved on your phone. The app doesn't even ask for internet permission.

I don't hear any audio. What can I do?

Audio uses your phone's Japanese text-to-speech voice. Go to Settings › Accessibility › Text-to-speech, choose your speech engine (usually Google) and download the Japanese language. This one-time download needs internet; after that it works offline.

Is it safe to install an APK from GitHub?

Only install apps from sources you trust. KOTOBA's download comes straight from this project's official GitHub Releases page, and the app requests only notification and start-up permissions for optional study reminders.

Will I lose my progress if I update?

No. Installing a newer version over the old one keeps everything. Uninstalling the app removes your progress unless Android's Google backup is turned on.

Is there an iPhone version?

Not yet. KOTOBA is Android only for now.
